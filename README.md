# 月考冲刺站 · 高二上第一次月考六科备考（学科分页版）

面向广东新高考物理类组合高二上学期第一次月考的交互式复习网站。

## 特点

- **学科分页**：语文 / 数学 / 英语 / 物理 / 化学 / 生物各自独立成页，首页选科进入，顶部导航随时切换
- **闪卡式交互**：选科卡片、二级结论、作文素材、语法要点、解题方法全部支持 3D 翻卡
- **单词闪卡**：49 个选必一 Unit 1–5 高频词 + 高一词汇，认识 / 不认识自测，支持打乱、搜索、词表
- **素材库**：15 条作文素材（9 人物 + 6 名言），主题筛选 + 已背标记
- **知识导图**：六科同步知识导图（章节 → 高频考点 → 关键结论），学科 tab 即时切换，节点可展开折叠
- **考点训练场**：六科题库（判断 + 单选），每科随机抽 5 题逐题判分、附解析，自动记录本科最高分
- **规划工具**：月考倒计时（可改日期）、复习计划按剩余天数自动划分阶段、各科时间占比图、每科打卡清单
- **进阶内容**：六科写作模板 / 规范步骤 / 高分表达 / 典型模型 / 图像模板 / 概念辨析翻卡，加各科速查表（文言句式与断句四法、向量结论与题型、虚拟语气与词形变化、电势四法与场强三法、吸放热与热化学、激素本质与调节辨析）与考点自测题
- **进度本地保存**：单词、素材、打卡、训练最高分存于浏览器 localStorage

## 考试范围

- 语文：统编选择性必修上册
- 数学：人教 A 版选必一第 1 章（到空间向量为止）
- 英语：人教版选必一 Unit 1–5（考部分）+ 高一词汇回顾
- 物理：人教版必修第三册第 9–11 章（静电场及其应用 / 静电场中的能量 / 电路及其应用）
- 化学：人教版选必 1 第 1–2 章（反应热 / 化学反应速率与化学平衡）
- 生物：人教版选必 1 第 1–2 章 + 第 3 章第 1 节（内环境与稳态 / 神经调节 / 激素与内分泌系统）

具体以老师通知为准。
