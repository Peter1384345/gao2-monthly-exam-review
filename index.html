02

可以使用的资料

按「先教材、再专项、后真题」的顺序搭配使用

教材与课堂笔记

  • 教科书：人教版（2019）选必各册 + 必修第三册，逐节回看例题与「思考与讨论」。
  • 课堂笔记 / 导学案：老师圈过的重点、补充结论，是月考命题的直接依据。
  • 课后习题：教材练习、习题 A/B 组重做一遍，很多月考原题从这里改编。
优先级最高，第一轮复习的核心载体。

教辅刷题

  • 基础层：《一遍过》《教材帮》——跟课同步，补概念漏洞。
  • 提升层：《五年高考三年模拟》《必刷题》——按章节专题练，量够、题型全。
  • 冲刺层：《高考必刷卷》《试题调研》、金考卷单元卷——成套模拟，练速度。
选 1–2 套主刷即可，贪多嚼不烂。

真题与试卷

  • 高考真题：近 5 年对应模块真题（静电场、化学反应原理、空间向量等），明确命题风格。
  • 月考 / 期中 / 期末卷：本省各地市卷、联考卷，范围最贴近；学科网、21 世纪教育网可下载。
  • 往年本校卷：同校往届月考卷最有参考价值（若老师分享过）。
成套限时做，做完按考点归类复盘。

网课与 App

  • 国家中小学智慧教育平台：免费官方同步课，概念没听懂时回看。
  • B 站：专题讲解（静电场、化学平衡、空间向量等），选口碑好的 UP 主。
  • 作业帮 / 猿题库：搜题、错题同类题练习。
  • 墨墨背单词 / 百词斩：英语词汇每天 20–30 分钟滚动背。
网课是补缺工具，不是复习主力，控制用时。

自建资料

  • 错题本：按科目整理典型错题，标注错因 + 正解 + 变式。
  • 公式 / 概念卡：物理电场公式、化学 K 表达式、生物概念做成卡片，随身背。
  • 思维导图：每章一张，先默写再对照课本补漏。
  • 作文素材本：语文议论文素材 3–5 个，反复用熟。
考前最后一天只看错题本和背诵卡。
03

13 天复习计划

以月考日期倒推 · 四个阶段 · 每天 6–7 小时有效学习

第 1–2 天

摸底诊断 · 定计划

各科各做 10 题摸底（或翻错题本），标出薄弱章节；排出每日任务表：6 科各 1 个专项 + 单词 / 默写零散任务。

第 3–6 天

回归教材 · 一轮梳理

逐章过教材 + 笔记：物理电场与电路、化学反应热与平衡、数学空间向量、生物内环境与神经调节为重点；每天抽 30 分钟补高一基础薄弱点。

第 7–10 天

专题刷题 · 错题攻坚

按考点做专题（盖斯定律、三段式、建系法、带电粒子、电路、语法专项），做完立即归类错题；英语每天 1 篇阅读 + 词汇滚动。

第 11–12 天

真题模拟 · 查漏补缺

每天 1–2 套限时卷（理综式安排物理 / 化学 / 生物），严格计时；对答案后把失分点回教材再补一遍。

第 13 天

考前调整 · 只看精华

只看错题本、公式卡、背诵篇目；不刷新题，早睡，调整生物钟和考试用品（2B 铅笔、黑色签字笔、直尺、橡皮）。

04

各科每日时间占比建议

按月考范围大小与计算量分配，可按个人薄弱点调整 ±5%

语文

统编选择性必修上册 · 月考范围：文言文单元（先秦诸子）+ 古诗词诵读 + 现代文阅读与写作
优先度 · 中每天 40–50 分钟零散时间背默

最可能考到的地方

文言实词 / 虚词文言翻译（采分点）文言句式与断句 课内背诵默写论述类文本阅读散文 / 小说阅读 语言文字运用（病句 / 成语 / 补写）材料作文（议论文）

复习策略

  1. 回归课本：选必上册要求背诵的文言篇目和古诗词逐篇背默过关，文言注释（实词、词类活用、特殊句式）画出来背。
  2. 文言专项：每天 1 篇课外文言阅读，训练断句、实词推断、翻译采分点（重点词 + 句式）。
  3. 作文备料：整理 3–5 个通用素材（人物、事件、名言），学议论文「引–议–联–结」结构，练 1–2 篇限时作文。
  4. 限时阅读：论述类 + 文学类各 1 篇，控制在 20 分钟内，对答案后复盘错因。
  5. 基础回归：高一基础文言实词、虚词、文化常识滚动复习，默写题偶有跨册篇目。
易错提醒：翻译题漏采分点；默写丢分（错别字）；作文偏题——先抓「材料核心词 + 任务要求」再审题，立意要直接回应材料。

数学

人教A版选择性必修第一册 · 月考范围：第1章 空间向量与立体几何（考到空间向量为止）
优先度 · 高每天 70–90 分钟优先级最高

最可能考到的地方

空间向量线性 / 数量积运算向量共线 / 共面判定建系法求线面角 / 二面角 / 距离 坐标运算法向量求解向量法证平行 / 垂直 点到平面距离向量法规范步骤

复习策略

  1. 基础回归：先把高一平面向量（线性运算、数量积、坐标表示）和立体几何初步（线面关系判定）快速过一遍，空间向量是它们的延伸。
  2. 公式过关：空间向量线性运算、数量积、模长与夹角公式、点到平面距离公式，全部能独立默写。
  3. 建系法专练：立体几何 80% 用「建系 + 求法向量」解，练熟坐标取点、法向量、cos 角计算，注意题目是否要求证明（几何法）。
  4. 规范答题：把「向量法解空间角 / 距离」典型题按标准步骤重做 2–3 道，防止会做但过程丢分。
易错提醒：建系时坐标取错（原点、轴方向）；法向量算错；线面角用 sin 取绝对值、二面角要判断锐 / 钝角；平行 / 垂直条件记混；证明题要求几何法时别直接用向量结论。

结论 01
建系三原则
点击翻面
对称性优先、垂直关系优先（两两垂直作轴）、取点方便优先（坐标尽量为整数）。
结论 02
法向量速求（叉乘）
点击翻面
n=(a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)，比解方程组快。
结论 03
线面角 sin，二面角判锐钝
点击翻面
线面角：sin θ = |cos<方向向量,法向量>|；二面角先由图形判锐 / 钝再定 cos 符号。
结论 04
点到平面距离
点击翻面
d = |PA·n| / |n|（P 为点，A 为面内任一点，n 为法向量）。
结论 05
平行 / 垂直向量判定
点击翻面
线线平行→方向向量共线；线面平行→方向向量⊥法向量；面面垂直→两法向量数量积为 0。

点击翻面

英语

人教版选择性必修一 · 月考范围：Unit 1–5（整册已教完，只考部分内容）+ 高一必修词汇回顾
优先度 · 中每天 40–50 分钟词汇用零散时间

最可能考到的地方

Unit 1–5 核心词汇短语（只考部分）高一必修词汇回顾非限制性定语从句 将来进行时-ing 作主语 / 宾语 / 表语主语从句 阅读理解（主旨 / 推断 / 词义）七选五完形填空语法填空应用文写作

复习策略

  1. 词汇滚动复习：选必一 Unit 1–5 单词短语按「英译汉 / 汉译英」双向往返背；同时滚动复习高一必修词汇，考前每天 30–50 个。
  2. 语法专项：重点吃透非限制性定语从句（不能用 that）和将来进行时；顺带复习 -ing 作主语 / 宾语 / 表语、主语从句，各练 10–15 题。
  3. 每天限时阅读：1 篇阅读 + 1 篇七选五或完形，卡时间做，培养阅读速度与耐心。
  4. 写作模板：背 2–3 篇应用文范文和高级句型，考前练写 1 篇。
易错提醒：非限制性定语从句误用 that / 关系代词缺失；将来进行时与一般将来时混用；语法填空忽略词性变化；完形「前后逻辑 + 复现词」没抓到。

物理

人教版必修第三册 · 月考范围：第9章 静电场及其应用 + 第10章 静电场中的能量 + 第11章 电路及其应用
优先度 · 高每天 60–75 分钟优先级最高

最可能考到的地方

电荷守恒 / 库仑定律场强 / 电势 / 电势能 / 电势差U = Ed（匀强电场） 电容器的电容带电粒子在电场中的运动（加速 / 偏转） 电流定义式 I = q/t欧姆定律与电阻定律串并联电路规律 电表改装伏安法测电阻（内接 / 外接）多用电表

复习策略

  1. 公式体系梳理：把 E、φ、U、C、F电、W电、Ep 及相互关系整理成一张网络，弄清每个量「由谁决定」。
  2. 抓图景：电场线 + 等势面的分布图要会看会画，判断场强大小、电势高低、电荷移动做功正负。
  3. 带电粒子运动：加速用动能定理，偏转按类平抛分解（水平匀速、竖直匀加速），练 2–3 道综合大题。
  4. 电路专练：串并联规律、电表改装原理、伏安法内外接判断（看 Rx 与 RA、RV 的关系）、多用电表读数。
  5. 基础回归：静电场大题常与高一「受力分析、牛顿定律、动能定理」结合，考前把这三块基础题各练几道热身。
易错提醒：场强大与电势高不是一回事；电场力做正功电势能减小；U=Ed 要沿场强方向；R=U/I 是定义式、R=ρL/S 才是决定式；伏安法内接测大电阻、外接测小电阻；多用电表读数注意量程与挡位。

二级结论闪卡 · 静电场（点击翻面）

结论 01
电场线与等势面
点击翻面
处处垂直；沿电场线方向电势降低最快；等势面越密场强越大。
结论 02
电势能「正高负低」
点击翻面
Ep=qφ：正电荷在高电势处电势能大，负电荷相反——先看电荷正负。
结论 03
电场力做功与路径无关
点击翻面
W=qU；W>0 电势能减小，W<0 电势能增大。
结论 04
匀强电场电势均匀变化
点击翻面
U=Ed，d 为沿场强方向距离；「电势差与距离成正比」只沿场强方向成立。
结论 05
等量异种电荷中垂面
点击翻面
中垂面为等势面（电势 0，取无穷远为 0 时）；中点合场强最小但不为 0。
结论 06
电容动态分析两步走
点击翻面
先判断 Q 不变（断开）还是 U 不变（连着）；再用 C=εS/4πkd → C=Q/U → E=U/d 推。
结论 07
带电粒子偏转（类平抛）
点击翻面
偏移量 y=qUL²/(2mdv₀²)，tanθ=qUL/(mdv₀²)；同一加速场后比荷相同则偏转相同。
结论 08
密立根油滴实验思想
点击翻面
悬浮平衡时 qE=mg，由 E、m 反推元电荷——「平衡法」求电荷量模型。

二级结论闪卡 · 电路（点击翻面）

结论 09
定义式 vs 决定式
点击翻面
R=U/I 是定义式；R=ρL/S 是决定式；ρ 只与材料和温度有关。
结论 10
串并联分配规律
点击翻面
串联电流相等、电压按电阻正比；并联电压相等、电流按电阻反比分配。
结论 11
伏安法「大内偏大，小外偏小」
点击翻面
Rₓ≫R_A 内接（偏大）；Rₓ≪R_V 外接（偏小）；比较 Rₓ² 与 R_A·R_V 判断。
结论 12
电表改装
点击翻面
电压表：串大电阻 R=(n−1)R_g；电流表：并小电阻 R=R_g/(n−1)。
结论 13
多用电表读数
点击翻面
欧姆挡：读数 × 倍率；电流 / 电压挡：看最小分度按 1/2/5 原则估读。
结论 14
滑动变阻器两种接法
点击翻面
分压式：电压可从 0 起连续调（测伏安特性必用）；限流式：省电但调不到 0。

化学

人教版选择性必修1《化学反应原理》 · 月考范围：第1章 反应热 + 第2章 化学反应速率与化学平衡
优先度 · 高每天 55–70 分钟优先级高

最可能考到的地方

焓变与热化学方程式盖斯定律计算化学反应速率（三段式） 影响速率的因素化学平衡状态判断平衡常数 K 与浓度商 Q 勒夏特列原理转化率计算v–t / c–t 图像分析 化学反应的方向（自发反应）化学反应的调控（合成氨）

复习策略

  1. 盖斯定律专项：热化学方程式加减、乘系数、方向翻转要熟练，注意 ΔH 符号与数值同步变化，练 5 道计算题。
  2. 三段式通法：速率、转化率、平衡浓度全部用「起始–变化–平衡」三段式，格式固定、计算规范。
  3. K 与平衡移动：会写 K 的表达式（固 / 纯液不写入），会用 Q 与 K 比较判断方向，理解勒夏特列原理。
  4. 图像分析：v–t、c–t、转化率—温度 / 压强图逐图训练，先看横纵坐标再判断「条件改变对哪个量影响」。
  5. 基础回归：反应热、速率计算都依赖高一「物质的量、物质的量浓度、氧化还原、离子反应」基础，薄弱处优先补。
易错提醒：热化学方程式漏标物质状态 / ΔH 符号写反；K 表达式把固体液体写进去；催化剂改变速率但不改变平衡；压强只对有气体参与的反应有影响。

二级结论闪卡 · 反应热与平衡（点击翻面）

结论 01
盖斯定律本质
点击翻面
反应热只与始态、终态有关；方程式相加减，ΔH 同步相加减；反转方程式 ΔH 变号。
结论 02
三段式模板
点击翻面
起始 / 变化 / 平衡三行；变化量之比 = 化学计量数之比；转化率 = 变化 ÷ 起始。
结论 03
K 的书写与判断
点击翻面
K 只与温度有关；固 / 纯液不写入；Q>K 逆向，Q<K 正向，Q=K 平衡。
结论 04
勒夏特列「只减弱不消除」
点击翻面
平衡向减弱这种改变的方向移动，但只能部分抵消、不能完全消除。
结论 05
催化剂的两不变
点击翻面
改变活化能与速率，但不改变平衡位置、不改变 ΔH、不改变 K。
结论 06
压强影响的适用范围
点击翻面
只对有气体参与且系数和不相等的反应有影响；恒容充惰气，浓度不变、平衡不移动。
结论 07
K–T 判断吸放热
点击翻面
升温 K 增大 → 正向吸热；升温 K 减小 → 正向放热。
结论 08
v–t 图读突变
点击翻面
正逆速率同时突变 → 温度或催化剂；一个突变一个渐变 → 浓度；压强看气体系数差。

步骤 01
写方程式
点击翻面
先配平，标出已知物质的起始浓度 / 物质的量。
步骤 02
设变化量
点击翻面
按化学计量数设 x，变化量 = 系数 × x。
步骤 03
求平衡量
点击翻面
平衡 = 起始 ± 变化（反应物减、生成物加）。
步骤 04
套公式
点击翻面
速率 v=Δc/Δt；转化率 = 变化 ÷ 起始；K 用平衡浓度代入。

生物

人教版选择性必修1《稳态与调节》 · 月考范围：第1章 内环境与稳态 + 第2章 神经调节 + 第3章第1节 激素与内分泌系统
优先度 · 中每天 45–60 分钟优先背记

最可能考到的地方

内环境的组成（血浆 / 组织液 / 淋巴）内环境理化性质稳态调节机制 反射弧神经冲动的产生与传导突触传递（单向性） 内分泌系统的组成激素的发现（促胰液素）常见内分泌腺与激素功能 激素的分级调节 / 反馈调节（视进度）

复习策略

  1. 概念图梳理：画「内环境成分」关系图，分清哪些属于内环境、哪些不属于（消化道、泪液、汗液等）。
  2. 神经调节默写：静息电位（K⁺外流）与动作电位（Na⁺内流）、突触传递单向性、反射弧五部分，能默写并能画出传导路径。
  3. 内分泌与激素：记住各内分泌腺分泌的激素及其功能（下丘脑、垂体、甲状腺、胰岛等），熟悉「激素的发现——促胰液素」实验史；若进度快补充血糖调节与分级 / 反馈调节。
  4. 比较记忆：神经调节（快、准、短）vs 体液调节（慢、广、长），考试常考二者关系。
易错提醒：误把消化道 / 汗液当内环境；静息 / 动作电位离子搞反；突触传递只能单向（递质只由突触前膜释放）；激素运输到全身但只作用于靶器官 / 靶细胞。

二级结论闪卡 · 稳态与调节（点击翻面）

结论 01
内环境的边界
点击翻面
内环境 = 细胞外液（血浆、组织液、淋巴）；消化道、泪液、汗液、尿液不属于内环境。
结论 02
电位变化的离子本质
点击翻面
静息：K⁺外流（外正内负）；动作：Na⁺内流（外负内正）；恢复靠 Na⁺-K⁺泵耗 ATP。
结论 03
突触传递只能单向
点击翻面
递质只能由突触前膜释放，作用于突触后膜受体；信号：电 → 化学 → 电。
结论 04
反射弧五部分
点击翻面
感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器；任一环节受损反射不完成，但感觉可产生。
结论 05
激素是信息分子
点击翻面
微量高效、体液运输、只作用于靶器官 / 靶细胞；不参与代谢、不供能、不组成结构。
结论 06
下丘脑是调节枢纽
点击翻面
神经调节与体液调节的枢纽；体温、水盐平衡调节中枢都在下丘脑。
结论 07
甲状腺激素分级调节链
点击翻面
下丘脑 →TRH→ 垂体 →TSH→ 甲状腺 → 甲状腺激素；增多后反馈抑制上游（负反馈）。
结论 08
神经 vs 体液调节
点击翻面
神经快、准、短；体液慢、广、长；以神经调节为主、体液调节为辅。
