语文文言 · 阅读 · 写作

统编选择性必修上册 · 月考范围：文言文单元（先秦诸子）+ 古诗词诵读 + 现代文阅读与写作
优先度 · 中每天 40–50 分钟零散时间背默

复习策略

  1. 回归课本：选必上册要求背诵的文言篇目和古诗词逐篇背默过关，文言注释（实词、词类活用、特殊句式）画出来背。

易错提醒：翻译题漏采分点；默写丢分（错别字）；作文偏题——先抓「材料核心词 + 任务要求」再审题，立意要直接回应材料。

句式标志词教材常见例句

文言词义 · 点题判读（点击展开答案）

01「君子喻于义」中「喻」意为「明白、懂得」
正确。「喻」在此为使明白 / 懂得义，与「晓」义近。
02「自矜者不长」中「矜」意为「怜悯」
错误。「矜」在此为「夸耀」义，整句意为自夸的人不能长久。
03「民之从事」中「之」用于取消句子独立性
正确。主谓之间的「之」取消独立性，整个短语作全句主语。
04「其正色邪」中「其」表揣测语气
正确。表推测语气，可译为「大概、或许」，与「邪」呼应构成疑问。

数学空间向量 · 立体几何

人教A版选择性必修第一册 · 月考范围：第1章 空间向量与立体几何（考到空间向量为止）
优先度 · 高每天 70–90 分钟优先级最高

最可能考到的地方

空间向量线性 / 数量积运算向量共线 / 共面判定建系法求线面角 / 二面角 / 距离 坐标运算法向量求解向量法证平行 / 垂直 点到平面距离向量法规范步骤

复习策略

  1. 基础回归：先把高一平面向量（线性运算、数量积、坐标表示）和立体几何初步（线面关系判定）快速过一遍，空间向量是它们的延伸。
  2. 公式过关：空间向量线性运算、数量积、模长与夹角公式、点到平面距离公式，全部能独立默写。
  3. 建系法专练：立体几何 80% 用「建系 + 求法向量」解，练熟坐标取点、法向量、cos 角计算，注意题目是否要求证明（几何法）。
  4. 规范答题：把「向量法解空间角 / 距离」典型题按标准步骤重做 2–3 道，防止会做但过程丢分。
易错提醒：建系时坐标取错（原点、轴方向）；法向量算错；线面角用 sin 取绝对值、二面角要判断锐 / 钝角；平行 / 垂直条件记混；证明题要求几何法时别直接用向量结论。

二级结论闪卡（点击翻面）

结论 01
建系三原则
点击翻面
对称性优先、垂直关系优先（两两垂直作轴）、取点方便优先（坐标尽量为整数）。
结论 02
法向量速求（叉乘）
点击翻面
n=(a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)，比解方程组快。
结论 03
线面角 sin，二面角判锐钝
点击翻面
线面角：sin θ = |cos<方向向量,法向量>|；二面角先由图形判锐 / 钝再定 cos 符号。
结论 04
点到平面距离
点击翻面
d = |PA·n| / |n|（P 为点，A 为面内任一点，n 为法向量）。
结论 05
平行 / 垂直向量判定
点击翻面
线线平行→方向向量共线；线面平行→方向向量⊥法向量；面面垂直→两法向量数量积为 0。
结论 06
四点共面充要条件
点击翻面
P∈平面ABC ⇔ 存在 x+y+z=1，使 OP = xOA + yOB + zOC。
结论 07
常见几何体建系
点击翻面
长方体 / 正方体取三条共点棱为轴；正棱锥取底面中心为原点、底面为 xOy 面。

步骤 01
向量法证线面垂直
点击翻面

点击翻面

点到平面距离三步
点击翻面

空间向量公式速查

名称公式备注
数量积a·b = |a||b|cosθ = x₁x₂ + y₁y₂ + z₁z₂垂直 ⟺ a·b = 0
模长|a| = √(x² + y² + z²)模长非负
夹角cosθ = a·b / (|a||b|)θ ∈ [0, π]
法向量n = a × b（行列式展开）建系求法常用
点面距离d = |PA·n| / |n|P 为面外一点
共线 / 共面a = λb；p = xa + yb基底表示法

概念判断 · 点题判读（点击展开答案）

01两向量垂直 ⟺ a·b = 0
正确。数量积为 0 是非零向量垂直的充要条件。
02若 a·b = 0，则 a、b 中至少有一个为零向量
错误。两个非零向量垂直时数量积同样为 0。
03线面角 θ 满足 sinθ = |a·n| / (|a||n|)
正确。线面角取方向向量与法向量夹角之余角。
04二面角余弦值恒等于两法向量夹角的余弦
错误。需结合图形判断锐钝角，符号可能相反。

向量高分结论 · 月考速记

结 01
投影法翻译数量积
点击翻面
a·b = |a| ×（b 在 a 方向投影长）。求夹角、最值、垂直先画几何投影，避免盲算坐标。
结 02
共线共面 · 系数和为 1
点击翻面
三点共线：系数和 x+y=1；四点共面：从同一起点出发，系数和 λ+μ+ν=1。出现即秒判「点共线 / 点共面」。
结 03
正四面体高频数据
点击翻面
棱长 a：高 √6/3·a，外接球半径 √6/4·a，内切球半径 √6/12·a，对棱互相垂直。选择填空直接用。
结 04
建系选点与法向量
点击翻面
优先找三条两两垂直的线作坐标轴；法向量用待定系数或叉积，先证两向量垂直再取积，别硬算。

题型秒题信号应对

最可能考到的地方

电荷守恒 / 库仑定律场强 / 电势 / 电势能 / 电势差U = Ed（匀强电场） 电容器的电容带电粒子在电场中的运动（加速 / 偏转） 电流定义式 I = q/t欧姆定律与电阻定律串并联电路规律 电表改装伏安法测电阻（内接 / 外接）多用电表

复习策略

  1. 公式体系梳理：把 E、φ、U、C、F电、W电、Ep 及相互关系整理成一张网络，弄清每个量「由谁决定」。
  2. 抓图景：电场线 + 等势面的分布图要会看会画，判断场强大小、电势高低、电荷移动做功正负。

人教版选择性必修1《化学反应原理》 · 月考范围：第1章 反应热 + 第2章 化学反应速率与化学平衡

最可能考到的地方

焓变与热化学方程式盖斯定律计算化学反应速率（三段式） 影响速率的因素化学平衡状态判断平衡常数 K 与浓度商 Q 勒夏特列原理转化率计算v–t / c–t 图像分析 化学反应的方向（自发反应）化学反应的调控（合成氨）

复习策略

  1. 盖斯定律专项：热化学方程式加减、乘系数、方向翻转要熟练，注意 ΔH 符号与数值同步变化，练 5 道计算题。
  2. 三段式通法：速率、转化率、平衡浓度全部用「起始–变化–平衡」三段式，格式固定、计算规范。
  3. K 与平衡移动：会写 K 的表达式（固 / 纯液不写入），会用 Q 与 K 比较判断方向，理解勒夏特列原理。

易错提醒：热化学方程式漏标物质状态 / ΔH 符号写反；K 表达式把固体液体写进去；催化剂改变速率但不改变平衡；压强只对有气体参与的反应有影响。

点击翻面

结论 03
K 的书写与判断
点击翻面
K 只与温度有关；固 / 纯液不写入；Q>K 逆向，Q<K 正向，Q=K 平衡。

热化学 + 平衡公式速查

名称内容备注
反应热ΔH = 生成物总能量 − 反应物总能量 = 反应物键能 − 生成物键能单位 kJ/mol
盖斯定律目标反应 ΔH = 分步反应 ΔH 的代数和与途径无关
反应速率v = Δc / Δt不同物质数值可不同
平衡常数K = [生成物]^幂 / [反应物]^幂只与温度有关
Q 判向Q > K 逆向；Q < K 正向任意时刻可判
转化率α = 变化量 / 起始量 ×100%三段式基础

概念判断 · 点题判读（点击展开答案）

01ΔH 的单位是 kJ/mol，数值与化学计量数成正比
正确。计量数翻倍 ΔH 也翻倍，单位不变。
02温度升高，任何反应平衡都正向移动
错误。升温利于吸热方向，放热反应会逆向移动。
03增大压强，平衡一定向气体分子数减小方向移动
错误。反应前后气体计量数相等时，压强改变不影响平衡。
04催化剂能改变平衡常数 K 的数值
错误。催化剂只改变反应速率，不改变平衡与 K。

常见吸热 / 放热反应速记

类型常见反应判断依据
放热燃烧；活泼金属与水 / 酸（Na+H₂O）；中和反应；大多数化合；铝热反应反应物总能量 > 生成物；断键吸热 < 成键放热
吸热大多数分解；Ba(OH)₂·8H₂O + NH₄Cl；C + CO₂；C + H₂O(g)；盐酸 + NaHCO₃ΔH > 0；常见「记死」的特例优先背

生物稳态 · 神经与激素调节

人教版选择性必修1《稳态与调节》 · 月考范围：第1章 内环境与稳态 + 第2章 神经调节 + 第3章第1节 激素与内分泌系统
优先度 · 中每天 45–60 分钟优先背记

最可能考到的地方

内环境的组成（血浆 / 组织液 / 淋巴）内环境理化性质稳态调节机制 反射弧神经冲动的产生与传导突触传递（单向性） 内分泌系统的组成激素的发现（促胰液素）常见内分泌腺与激素功能 激素的分级调节 / 反馈调节（视进度）

复习策略

  1. 概念图梳理：画「内环境成分」关系图，分清哪些属于内环境、哪些不属于（消化道、泪液、汗液等）。
  2. 神经调节默写：静息电位（K⁺外流）与动作电位（Na⁺内流）、突触传递单向性、反射弧五部分，能默写并能画出传导路径。
  3. 内分泌与激素：记住各内分泌腺分泌的激素及其功能（下丘脑、垂体、甲状腺、胰岛等），熟悉「激素的发现——促胰液素」实验史；若进度快补充血糖调节与分级 / 反馈调节。
  4. 比较记忆：神经调节（快、准、短）vs 体液调节（慢、广、长），考试常考二者关系。
易错提醒：误把消化道 / 汗液当内环境；静息 / 动作电位离子搞反；突触传递只能单向（递质只由突触前膜释放）；激素运输到全身但只作用于靶器官 / 靶细胞。

二级结论闪卡 · 稳态与调节（点击翻面）

结论 01
内环境的边界
点击翻面
内环境 = 细胞外液（血浆、组织液、淋巴）；消化道、泪液、汗液、尿液不属于内环境。
结论 02
电位变化的离子本质
点击翻面
静息：K⁺外流（外正内负）；动作：Na⁺内流（外负内正）；恢复靠 Na⁺-K⁺泵耗 ATP。
结论 03
突触传递只能单向
点击翻面
递质只能由突触前膜释放，作用于突触后膜受体；信号：电 → 化学 → 电。
结论 04
反射弧五部分
点击翻面
感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器；任一环节受损反射不完成，但感觉可产生。
结论 05
激素是信息分子
点击翻面
微量高效、体液运输、只作用于靶器官 / 靶细胞；不参与代谢、不供能、不组成结构。
结论 06
下丘脑是调节枢纽
点击翻面
神经调节与体液调节的枢纽；体温、水盐平衡调节中枢都在下丘脑。
结论 07
甲状腺激素分级调节链
点击翻面
下丘脑 →TRH→ 垂体 →TSH→ 甲状腺 → 甲状腺激素；增多后反馈抑制上游（负反馈）。
结论 08
神经 vs 体液调节
点击翻面
神经快、准、短；体液慢、广、长；以神经调节为主、体液调节为辅。

概念辨析 · 易混速分（点击翻面）

辨析 01
内环境成分判断
点击翻面
血浆、组织液、淋巴属于；汗液、尿液、泪液、消化液、消化道内容物不属于。
辨析 02
静息 vs 动作电位
点击翻面
静息：K⁺外流、外正内负；动作：Na⁺内流、外负内正；恢复需 Na⁺-K⁺泵耗 ATP。
辨析 03
传导方向对比
点击翻面
神经纤维上兴奋可双向传导；突触处只能单向传递（递质仅由突触前膜释放）。
辨析 04
激素 vs 酶 vs 递质
点击翻面
激素：体液运输、作用于靶器官；递质：突触间隙扩散、作用于受体；酶：催化反应，三者均不供能。
辨析 05
神经 vs 体液调节
点击翻面
神经：快、准、短；体液：慢、广、长；二者相互配合，以神经调节为主。
辨析 06
分级 vs 反馈调节
点击翻面
下丘脑 → 垂体 → 靶腺为分级调节；产物增多抑制上游为负反馈（维持稳态的关键）。

概念判断 · 点题判读（点击展开答案）

01血糖升高→胰岛素增多→血糖下降，属于负反馈调节

错误。由垂体分泌，作用于甲状腺。

稳态与调节 · 易错辨析

辨 01
体液 ≠ 激素调节
点击翻面
体液调节包含激素调节，还含 CO₂、H⁺ 等化学物质调节；生命活动以神经调节为主，体液调节为辅。
辨 02
外分泌液不是体液
点击翻面
汗液、泪液、尿液、消化液通过管道与外界相通，属于外分泌液，不属于体液；体液=细胞内液+细胞外液。
辨 03
神经电位口诀
点击翻面
静息「想加」：K⁺ 外流维持；动作「想律」：Na⁺ 内流形成；两种跨膜方式都是协助扩散。
辨 04
激素作用与灭活
点击翻面
激素随体液运输到全身，只与靶细胞特异性受体结合起作用；发挥作用后立即被灭活，需不断分泌。
