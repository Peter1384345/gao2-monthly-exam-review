各科 · 考点与复习策略

高频考点 · 复习动作 · 易错提醒 · 建议用时

语

语文

统编选择性必修上册 · 月考范围：文言文单元（先秦诸子）+ 古诗词诵读 + 现代文阅读与写作

最可能考到的地方

文言实词 / 虚词文言翻译（采分点）文言句式与断句 课内背诵默写论述类文本阅读散文 / 小说阅读 语言文字运用（病句 / 成语 / 补写）材料作文（议论文）

建议用时

每天 40–50 分钟 · 零散时间背默

复习策略

  1. 回归课本：把选必上册要求背诵的文言篇目和古诗词逐篇背默过关，文言注释（实词、词类活用、特殊句式）画出来背。
  2. 文言专项：每天 1 篇课外文言阅读，训练断句、实词推断、翻译采分点（重点词 + 句式）。
  3. 作文备料：整理 3–5 个通用素材（人物、事件、名言），学议论文「引–议–联–结」结构，练 1–2 篇限时作文。
  4. 限时阅读：论述类 + 文学类各 1 篇，控制在 20 分钟内，对答案后复盘错因。
  5. 基础回归：高一学过的基础文言实词、虚词、文化常识滚动复习，默写题偶有跨册篇目。
易错提醒：翻译题漏采分点；默写丢分（错别字）；作文偏题——先抓「材料核心词 + 任务要求」再审题，立意要直接回应材料。
数

数学

人教A版选择性必修第一册 · 月考范围：第1章 空间向量与立体几何（考到空间向量为止）

最可能考到的地方

空间向量及其线性 / 数量积运算向量共线 / 共面判定建系法求线面角 / 二面角 / 距离 空间向量坐标运算法向量求解向量法证平行 / 垂直 点到平面距离立体几何中的向量法规范步骤

建议用时

每天 70–90 分钟 · 优先级最高

复习策略

  1. 基础回归：先把高一平面向量（线性运算、数量积、坐标表示）和立体几何初步（线面关系判定）快速过一遍，空间向量是它们的延伸。
  2. 公式过关：空间向量线性运算、数量积、模长与夹角公式、点到平面距离公式，全部能独立默写。
  3. 建系法专练：立体几何 80% 用「建系 + 求法向量」解，练熟坐标取点、法向量、cos 角计算，注意题目是否要求证明（几何法）。
  4. 规范答题：把「向量法解空间角 / 距离」的典型题按标准步骤重做 2–3 道，防止会做但过程丢分。
易错提醒：建系时坐标取错（原点、轴方向）；法向量算错；线面角用 sin 取绝对值、二面角要判断锐角 / 钝角；向量平行 / 垂直条件记混；证明题要求几何法时别直接用向量结论。
英

英语

人教版选择性必修一 · 月考范围：Unit 1–5（整册已教完，只考部分内容）+ 高一必修词汇回顾

最可能考到的地方

Unit 1–5 核心词汇短语（只考部分）高一必修词汇回顾非限制性定语从句 将来进行时-ing 作主语 / 宾语 / 表语主语从句 阅读理解（主旨 / 推断 / 词义）七选五完形填空语法填空应用文写作

建议用时

每天 40–50 分钟 · 词汇利用零散时间

复习策略

  1. 词汇滚动复习：选必一 Unit 1–5 单词短语按「英译汉 / 汉译英」双向往返背；同时滚动复习高一必修词汇，考前每天 30–50 个。
  2. 语法专项：重点吃透非限制性定语从句（不能用 that）和将来进行时；顺带复习 -ing 作主语 / 宾语 / 表语、主语从句，各练 10–15 题。
  3. 每天限时阅读：1 篇阅读 + 1 篇七选五或完形，卡时间做，培养阅读速度与耐心。
  4. 写作模板：背 2–3 篇应用文范文和高级句型，考前练写 1 篇。
易错提醒：非限制性定语从句误用 that / 关系代词缺失；将来进行时与一般将来时混用；语法填空忽略词性变化；完形「前后逻辑 + 复现词」没抓到。
物

物理

人教版必修第三册 · 月考范围：第9章 静电场及其应用 + 第10章 静电场中的能量 + 第11章 电路及其应用

最可能考到的地方

电荷守恒 / 库仑定律电场强度 / 电势 / 电势能 / 电势差U = Ed（匀强电场） 电容器的电容带电粒子在电场中的运动（加速 / 偏转） 电流定义式 I = q/t欧姆定律与电阻定律串并联电路规律 电表改装（电压表 / 电流表）伏安法测电阻（内接 / 外接）多用电表的使用

建议用时

每天 60–75 分钟 · 优先级最高

复习策略

  1. 公式体系梳理：把 E、φ、U、C、F电、W电、Ep 及相互关系整理成一张网络，弄清每个量「由谁决定」。
  2. 抓图景：电场线 + 等势面的分布图要会看会画，判断场强大小、电势高低、电荷移动做功正负。
  3. 带电粒子运动：加速用动能定理，偏转按类平抛分解（水平匀速、竖直匀加速），练 2–3 道综合大题。
  4. 电路专练：串并联电流 / 电压 / 电阻规律、电表改装原理、伏安法内外接判断（看 Rx 与 RA、RV 的关系）、多用电表读数。
  5. 基础回归：静电场大题常与高一「受力分析、牛顿定律、动能定理」结合，考前把这三块基础题各练几道热身。
易错提醒：场强大与电势高不是一回事；电场力做正功电势能减小；U=Ed 要沿场强方向；R=U/I 是定义式、R=ρL/S 才是决定式；伏安法内接测大电阻、外接测小电阻；多用电表读数注意量程与挡位。
化

化学

人教版选择性必修1《化学反应原理》 · 月考范围：第1章 反应热 + 第2章 化学反应速率与化学平衡

最可能考到的地方

焓变与热化学方程式盖斯定律计算化学反应速率（三段式） 影响速率的因素化学平衡状态判断平衡常数 K 与浓度商 Q 勒夏特列原理（温度 / 浓度 / 压强）转化率计算v–t / c–t 图像分析 化学反应的方向（自发反应）化学反应的调控（工业合成氨）

建议用时

每天 55–70 分钟 · 优先级高

复习策略

  1. 盖斯定律专项：热化学方程式加减、乘系数、方向翻转要熟练，注意 ΔH 符号与数值同步变化，练 5 道计算题。
  2. 三段式通法：速率、转化率、平衡浓度全部用「起始–变化–平衡」三段式，格式固定、计算规范。
  3. K 与平衡移动：会写 K 的表达式（固 / 纯液不写入），会用 Q 与 K 比较判断方向，理解勒夏特列原理。
  4. 图像分析：v–t、c–t、转化率—温度 / 压强图逐图训练，先看横纵坐标再判断「条件改变对哪个量影响」。
  5. 基础回归：反应热、速率计算都依赖高一「物质的量、物质的量浓度、氧化还原、离子反应」基础，薄弱处优先补。
易错提醒：热化学方程式漏标物质状态 / ΔH 符号写反；K 表达式把固体液体写进去；催化剂改变速率但不改变平衡；压强只对有气体参与的反应有影响。
生

生物

人教版选择性必修1《稳态与调节》 · 月考范围：第1章 内环境与稳态 + 第2章 神经调节 + 第3章第1节 激素与内分泌系统

最可能考到的地方

内环境的组成（血浆 / 组织液 / 淋巴）内环境理化性质稳态调节机制（神经–体液–免疫） 反射弧神经冲动的产生与传导突触传递（单向性） 内分泌系统的组成激素的发现（促胰液素）常见内分泌腺与激素功能 激素分泌的分级调节 / 反馈调节（视进度）

建议用时

每天 45–60 分钟 · 优先背记

复习策略

  1. 概念图梳理：画「内环境成分」关系图，分清哪些属于内环境（血浆 / 组织液 / 淋巴）、哪些不属于（消化道、泪液、汗液等）。
  2. 神经调节默写：静息电位（K⁺外流）与动作电位（Na⁺内流）、突触传递单向性、反射弧五部分，能默写并能画出传导路径。
  3. 内分泌与激素：记住各内分泌腺分泌的激素及其功能（下丘脑、垂体、甲状腺、胰岛等），熟悉「激素的发现——促胰液素」实验史；若进度快，补充血糖调节与甲状腺激素的分级 / 反馈调节。
  4. 比较记忆：神经调节（快、准、短）vs 体液调节（慢、广、长）对比记忆，考试常考二者关系。
易错提醒：误把消化道 / 汗液当内环境；静息 / 动作电位离子搞反；突触传递只能单向（递质只由突触前膜释放）；激素运输到全身但只作用于靶器官 / 靶细胞；内分泌腺与激素的对应关系易混。
03

二级结论速查

考场上可以直接用的结论 · 点击展开 · 按科目归类

数

数学 · 空间向量与立体几何

7 条
建系三原则
对称性优先（图形对称轴作坐标轴）、垂直关系优先（两两垂直的棱作轴）、取点方便优先（坐标尽量为整数）。
法向量速求（叉乘法）
两个向量 a=(a₁,a₂,a₃)、b=(b₁,b₂,b₃)，法向量 n = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)，比解方程组快。
线面角用 sin，二面角判锐钝
线面角 θ：sin θ = |cos<方向向量, 法向量>|；二面角先由图形判断锐 / 钝再定 cos 符号，不能只取绝对值。
点到平面距离
d = |PA·n| / |n|（P 为点，A 为平面内任一点，n 为法向量）——比体积法等更省步骤。
平行 / 垂直的向量判定
线线平行 → 方向向量共线；线面平行 → 方向向量 ⊥ 法向量（且线不在面内）；面面垂直 → 两法向量数量积为 0。
四点共面充要条件
O、A、B、C、P 中 P 在平面 ABC 内 ⇔ 存在 x+y+z=1 使 OP = xOA + yOB + zOC。
常见几何体建系
长方体 / 正方体直接取三条共点棱为轴；正棱锥取底面中心为原点、底面为 xOy 面；建系后所有点坐标都可写出。
物

物理 · 静电场

8 条
电场线与等势面
电场线与等势面处处垂直；沿电场线方向电势降低最快；等势面越密场强越大。
电势能口诀「正高负低」
Ep = qφ：正电荷在高电势处电势能大，负电荷在高电势处电势能小——判断电势能变化先看电荷正负。
电场力做功与路径无关
W = qU（与路径无关）；W>0 电势能减小，W<0 电势能增大。
匀强电场电势均匀变化
U = Ed，d 为沿场强方向的距离；同一等势面上电势相等，「电势差与距离成正比」只沿场强方向成立。
等量异种电荷连线中垂面
中垂面是等势面（电势为 0，取无穷远为 0 时）；中点处合场强最小但不为 0，电场线垂直中垂面。
电容动态分析两步走
① 先判断 Q 不变（与电源断开）还是 U 不变（与电源保持连接）；② 用 C=εS/4πkd 推 C，再用 C=Q/U 和 E=U/d 推 U、E。
带电粒子偏转（类平抛）
偏移量 y = qUL²/(2mdv₀²)，偏转角 tanθ = qUL/(mdv₀²)；经同一加速电场加速后，比荷相同（q/m 相同）的粒子偏转相同。
密立根油滴实验思想
油滴悬浮平衡时 qE = mg，由 E、m 反推元电荷——「平衡法」求电荷量的经典模型。
物

物理 · 电路

6 条
定义式 vs 决定式
R=U/I 是定义式（比值定义，与 U、I 无关）；R=ρL/S 是决定式；电阻率 ρ 只与材料和温度有关。
串并联分配规律
串联：电流相等，电压按电阻正比分配 U₁:U₂=R₁:R₂；并联：电压相等，电流按电阻反比 I₁:I₂=R₂:R₁。
伏安法口诀「大内偏大，小外偏小」
Rₓ 远大于 R_A → 内接（测量值偏大）；Rₓ 远小于 R_V → 外接（测量值偏小）；比较 Rₓ² 与 R_A·R_V 判断。
电表改装
改装电压表：串联大电阻 R=(n−1)R_g（n 为量程倍数）；改装电流表：并联小电阻 R=R_g/(n−1)。
多用电表读数
欧姆挡：读数 × 倍率；电流 / 电压挡：看最小分度，按 1/2/5 原则估读（如 0.1 分度读到 0.01）。
滑动变阻器两种接法
分压式：电压可从 0 起连续调节（测伏安特性曲线必用）；限流式：省电但调不到 0。
化

化学 · 反应热与平衡

8 条
盖斯定律本质
反应热只与始态、终态有关，与路径无关；方程式相加相减，ΔH 同步相加相减；反转方程式 ΔH 变号。
三段式模板
起始 / 变化 / 平衡三行；变化量之比 = 化学计量数之比；转化率 = 变化量 ÷ 起始量 ×100%。
K 的书写与判断
K 只与温度有关；固体、纯液体不写入 K 表达式；Q > K 平衡逆向移动，Q < K 正向移动，Q = K 处于平衡。
勒夏特列「只减弱不消除」
改变一个条件，平衡向减弱这种改变的方向移动，但只能部分抵消，不能完全消除。
催化剂的两不变
催化剂改变活化能、改变速率，但不改变平衡位置、不改变 ΔH、不改变 K。
压强影响的适用范围
压强只对有气体参与且气体系数和不相等的反应有影响；恒容充入惰性气体，各组分浓度不变，平衡不移动。
K–T 判断吸放热
温度升高 K 增大 → 正向吸热；温度升高 K 减小 → 正向放热——图像题常用结论。
v–t 图读突变
速率同时突变（正逆速率都变）→ 改变温度或催化剂；一个突变一个渐变 → 改变浓度；压强要看有无气体及系数差。
生

生物 · 稳态与调节

8 条
内环境的边界
内环境 = 细胞外液（血浆、组织液、淋巴）；消化道、泪液、汗液、尿液、消化液不属于内环境；血红蛋白在红细胞内，不在内环境。
电位变化的离子本质
静息电位：K⁺外流（外正内负）；动作电位：Na⁺内流（外负内正）；恢复靠 Na⁺-K⁺泵消耗 ATP。
突触传递只能单向
神经递质只能由突触前膜释放，作用于突触后膜上的受体；信号由电信号→化学信号→电信号。
反射弧五部分
感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器；任何一环受损反射不能完成，但感觉仍可产生（传导到大脑皮层）。
激素是信息分子
激素微量高效、经体液运输、只作用于靶器官 / 靶细胞；不直接参与代谢、不提供能量、不组成细胞结构。
下丘脑是调节枢纽
下丘脑是神经调节与体液调节的枢纽；体温、水盐平衡调节中枢都在下丘脑。
甲状腺激素分级调节链
下丘脑 → TRH → 垂体 → TSH → 甲状腺 → 甲状腺激素；甲状腺激素增多会反馈抑制下丘脑和垂体（负反馈）。
神经 vs 体液调节
神经调节快、准、短；体液调节慢、广、长；机体以神经调节为主，体液调节为辅，两者相互配合。

英语 · 语法速查

选必一高频语法 · 规则 + 例句 + 易错点 · 点击切换

非限制性定语从句（Unit 1）

与先行词 / 主句之间用逗号隔开，起补充说明作用；引导词用 which / who / whom / whose / when / where，不能用 that，也不能省略。

例：Tom, who is my classmate, won the first prize.
例：He passed the exam, which made his parents happy.（修饰整个主句用 which）
易错：误用 that；先行词指人作宾语漏掉 whom / who；修饰整句时错用 which 以外的词。

将来进行时（Unit 2）

结构 will / be going to be doing；表示将来某一时刻正在发生或按计划 / 安排必定发生的事。

例：This time tomorrow I will be flying to Beijing.
例：Don't call me at 8 — I will be having a meeting.
易错：与一般将来时混淆——will do 表意愿 / 预测，will be doing 表进行中或既定安排。

-ing 形式作主语 / 宾语 / 表语（Unit 3–4）

作主语时谓语用单数；可用 it 作形式主语；作宾语用于 enjoy / finish / suggest / avoid 等动词后，以及介词后。

例：Swimming is good for our health.
例：It is no use crying over spilt milk.
例：He enjoys reading novels in his free time.
易错：动词作主语直接用原形；介词后接动词原形；固定搭配 to do / doing 记混（如 look forward to doing）。

主语从句（Unit 5）

由 that / what / whether / 疑问词引导的从句作主语；that 不作成分、不能省略；what 在从句中作成分。

例：What he said at the meeting is true.
例：That she won the game surprised us all.
例：Whether we go depends on the weather.
易错：that 从句作主语被误省；what / that 混用——有成分用 what，无成分用 that。

完形 / 语法填空技巧

完形：先通读抓主旨（首段 + 每段首句），再逐空带入；优先看「上下文逻辑（因果 / 转折 / 并列）+ 词汇复现」。

语法填空：有提示词——先判断词性（名 / 动 / 形 / 副）再变形（单复数、时态、语态、词性转换、非谓语）；无提示词——填介词 / 连词 / 冠词 / 代词。

例：非谓语先找逻辑主语——动词与主语是主动用 -ing / 被动用 -ed（如 the book written by him）。
易错：忽略词性变化；非谓语不找逻辑主语；固定搭配记忆不牢（be interested in, be used to doing…）。

方法工具箱

化学计算方法 · 生物读图法 · 物理实验方法 · 可逐步翻页

化学 · 三段式模板（盖斯定律通用）

任何速率 / 平衡计算先写三段式：起始 → 变化 → 平衡，变化量之比等于化学计量数之比。
1写方程式：先配平，标出已知物质的起始浓度 / 物质的量。
2设变化量：按化学计量数设 x，变化量 = 系数 × x。
3求平衡量：平衡 = 起始 ± 变化（反应物减、生成物加）。
4套公式：速率 v=Δc/Δt；转化率 = 变化 ÷ 起始；K 用平衡浓度代入。

生物 · 读图四步法（曲线 / 坐标图）

坐标图题先定「轴点线面」，不急着看答案选项。
1看轴：横轴自变量、纵轴因变量，确认单位与变量关系。
2看点：起点、终点、交点、拐点——拐点往往是「条件改变」的位置。
3看线：趋势（上升 / 下降 / 先升后平）与斜率（快慢变化）。
4看对比：多条曲线找差异（谁高谁低、谁先变），对应实验变量。

生物 · 模式图判读法（神经 / 内环境 / 激素）

三种高频模式图的快速判读口诀。
1反射弧图：找神经节或突触方向——突触由「突触前膜 → 突触后膜」，据此判断传入 / 传出。
2内环境成分图：血浆 ↔ 组织液 ↔ 淋巴呈三角关系，淋巴只能由组织液单向进入，再汇入血浆。
3激素调节图：沿「下丘脑 → 垂体 → 靶腺」箭头找分级；回指箭头（负反馈）抑制上游。
4电位曲线图：横轴时间，纵轴膜电位；先外正内负（静息）→ 反转为外负内正（动作）→ 再恢复。

物理 · 实验与图像方法（电路 + 电场）

实验题拿分靠「原理 → 读数 → 数据处理」三步，图像题靠斜率与截距。
1伏安法：先比 Rₓ 与 R_A、R_V 定内外接（口诀「大内偏大，小外偏小」）；滑动变阻器选分压还是限流看是否要求 U 从 0 起。
2U–I 图像：斜率绝对值 = 内阻 r（电源），纵截距 = 电动势 E。
3伏安特性曲线：I–U 图斜率 = 电阻的倒数；曲线弯曲说明电阻随温度 / 电压变化。
4电容实验：Q–U 图斜率 = 电容 C；充放电电流–时间图像与横轴围成面积 = 电荷量 Q。

13 天复习计划

以月考日期倒推 · 四个阶段 · 每天 6–7 小时有效学习

第 1–2 天

摸底诊断 · 定计划

各科各做 10 题摸底（或翻错题本），标出薄弱章节；把每日任务表排出来：每天 6 科各 1 个专项 + 单词 / 默写零散任务。

第 3–6 天

回归教材 · 一轮梳理

逐章过教材 + 笔记：物理电场与电路、化学反应热与平衡、数学空间向量、生物内环境与神经调节为重点；每天抽 30 分钟补高一基础薄弱点。

第 7–10 天

专题刷题 · 错题攻坚

按考点做专题（盖斯定律、三段式、建系法、带电粒子、电路、语法专项），做完立即归类错题；英语每天 1 篇阅读 + 词汇滚动。

第 11–12 天

真题模拟 · 查漏补缺

每天 1–2 套限时卷（理综式安排物理 / 化学 / 生物），严格计时；对答案后把失分点回教材再补一遍。

第 13 天

考前调整 · 只看精华

只看错题本、公式卡、背诵篇目；不刷新题，早睡，调整生物钟和考试用品（2B 铅笔、黑色签字笔、直尺、橡皮）。
